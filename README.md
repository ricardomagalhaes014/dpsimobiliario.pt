# DPS Imobiliário

Este repositório contém os ficheiros do site institucional da **DPS Imobiliário**.

## Sobre o projeto
O website apresenta informações sobre os serviços, o portfólio e os contactos da imobiliária. A intenção é fornecer uma presença online clara e responsiva, permitindo que clientes potenciais conheçam melhor a empresa.

## Tecnologias utilizadas
- **HTML5** para a estrutura das páginas.
- **CSS3** para estilos e layout responsivo.
- **JavaScript** para interação (quando necessário).
- Outros recursos como imagens, fontes e ícones incluídos na pasta `assets/`.

## Estrutura de pastas e ficheiros principais
- `index.html` – Página inicial do site.
- `404.html` – Página de erro personalizada.
- `robots.txt` e `sitemap.xml` – Arquivos para SEO e indexação.
- `CNAME` – Arquivo de configuração de domínio (caso esteja a usar GitHub Pages).
- `assets/` – Contém scripts, folhas de estilo e outros recursos estáticos.

## Como visualizar o site
Para ver o site localmente, basta abrir o ficheiro `index.html` num navegador moderno. Não é necessário configurar servidor; o site é completamente estático.
